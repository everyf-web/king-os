KING OS — синхронизация ПК / телефон

1. Создай бесплатный Supabase project.
2. SQL Editor → выполни SUPABASE_SETUP.sql.
3. Project Settings → API: скопируй Project URL и anon/public key.
4. King OS → Настройки → вставь URL и key.
5. Введи один и тот же email/пароль на ПК и телефоне. На первом устройстве зарегистрируйся, затем войди.
6. Нажми Sync. На первом устройстве отправь локальную базу в облако; на втором при первом Sync выбери загрузку облачной базы.

После первого успешного Sync изменения автоматически отправляются в облако с небольшой задержкой. При обнаружении изменений одновременно на двух устройствах King OS не перезаписывает их молча и просит выполнить Sync вручную.
