KING OS V2.7.1

Исправлен выбор тренировок при наличии незавершённой тренировки.

- A / B / C / D показываются всегда.
- Пустую незавершённую тренировку можно удалить одной кнопкой.
- Если выбрать другую тренировку при пустой незавершённой — она просто заменяется выбранной.
- Если в незавершённой уже есть данные, King OS спросит подтверждение; старая сохранится как отменённая.
- Рекомендация A → B → C → D остаётся только рекомендацией.
