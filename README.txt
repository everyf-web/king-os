KING OS V1.6

Основные изменения:
- Работа теперь считается по времени: цель 10 часов в день (можно изменить в настройках).
- ЭВЕРИ, Dark EVERY и новый «Проект 3».
- Проект 3 может иметь разное название/смысл каждый день и не является отдельным обязательным пунктом.
- Если у проекта указано рабочее время, нужен результат дня минимум из двух слов.
- Рабочий день засчитывается, когда суммарно набрано >= цели и все записи с временем валидны.
- Tracker: отдельные серии Работа / Спорт / Чтение / Без зависимостей + общий счётчик идеальных дней.
- Календарь показывает рабочие часы вместо старого 0/2.
- Weekly Review включает рабочие часы по каждому проекту.
- Полный тренировочный план свёрнут на телефоне.
- Reading OS получил быстрые +15 / +5 минут.
- Редактирование прошлых дней поддерживает рабочие часы и Проект 3.

Важно:
- STORAGE KEY не менялся, накопленные данные сохраняются.
- Старые рабочие галочки без часов не превращаются автоматически в выдуманные часы. При необходимости старые дни можно отредактировать через Tracker.
