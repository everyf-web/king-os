KING OS V3.4.1 — SPORT / TRACKER UPDATE (08.11.2026)

ОСНОВА
V3.4.1 продолжает V3.4.0: свободные силовые тренировки на период 09.11–22.11, минимум 4 силовых в неделю, без обязательного шаблона тренировки.

ИЗМЕНЕНИЯ V3.4.1
• В каждой тренировке появилось расширяемое поле «Заметка к тренировке».
• У каждого упражнения внутри конкретной тренировки появилось отдельное расширяемое поле заметки. Заметки сохраняются вместе с тренировкой и остаются доступны после завершения.
• Вместо «последнего результата» во время тренировки показывается «лучший результат». Критерий: максимальный суммарный объём одной тренировки Σ(вес × повторения); если рабочего веса нет — сумма повторений. При равенстве берётся более свежая тренировка.
• В выборе упражнения также показывается лучший результат.
• В Tracker и дневном зачёте «Чтение» переименовано в «Чтение/Аудио». Модель хранения минут не менялась.
• Начиная с 08.11.2026 режим сна в зачёте требует только подъём. Отбой больше не нужно отмечать. Старые даты продолжают оцениваться по старым правилам, поэтому историческая статистика не пересчитывается.
• В редактировании дня после 08.11.2026 показывается только отметка подъёма; поле отбоя скрыто.

СОВМЕСТИМОСТЬ
• localStorage key king_os_v1 не менялся.
• Старые тренировки, подходы, упражнения, заметки, чтение, режим и остальная история сохраняются.
• Миграция V3.4 выполняется автоматически при первом запуске.

УСТАНОВКА
1. Перед обновлением желательно сделать ⚙ → Экспорт JSON.
2. Заменить файлы текущей версии файлами из этого ZIP.
3. После публикации проверить версию V3.4.1 возле даты.
4. Если PWA держит старый кэш, открыть приложение с ?repair=1.
