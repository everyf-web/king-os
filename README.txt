KING OS V3.0

ГЛАВНОЕ
- Новый основной экран «День» открывается при запуске.
- Расписание 09:00–02:00, шаг 30 минут.
- На ПК диапазон можно выделять мышью; на телефоне — нажать слот и задать время.
- Типы блоков: Работа, Силовая, Чтение, Личное, Другое.
- План сам по себе ничего не засчитывает.

ТАЙМЕР
- Встроен прямо в King OS.
- Можно запускать из рабочего блока расписания или отдельно.
- Старт / пауза / продолжить / завершить / сбросить.
- Прямой и обратный режим.
- Переключение отображения секунд.
- Завершённая сессия автоматически добавляет фактическое время в Work OS.
- Каждая сессия отдельно сохраняется в workSessions.
- Ручное редактирование итоговых часов по проекту сохраняется.

РАСПИСАНИЕ → ФАКТ
- Рабочий блок: время попадает в Work OS только после таймера или ручного ввода.
- Блок чтения: при отметке выполнения создаётся reading session на длительность блока.
- Силовая: учитывается только реально завершённая тренировка в Sport OS.
- Личные и прочие блоки можно отмечать выполненными вручную.

СПОРТ
- Бокс остаётся дополнительной активностью.
- Бокс больше не закрывает спортивное требование и не влияет на Tracker.
- Основная цель: 4 завершённые силовые за неделю.
- Tracker показывает X/4 силовых за текущую неделю.
- В обычный день силовая влияет на идеальный день только если она была поставлена в расписание.
- В полноценный выходной от работы силовая или отдельный выходной от силовой по-прежнему обязательны.

ИНТЕРФЕЙС
- Удалены placeholder-примеры и большая часть поясняющего текста.
- На ПК: расписание слева, таймер / сводка / дела справа.
- На телефоне: одноколоночная адаптация.
- Нижнее меню: Трекер · Работа · День · Спорт · Чтение.

СИНХРОНИЗАЦИЯ
- Добавлена опциональная синхронизация ПК / телефона через Supabase.
- Настройка выполняется в King OS → Настройки.
- Файлы SUPABASE_SETUP.sql и SYNC_SETUP.txt лежат рядом с приложением.
- После первого Sync изменения автоматически отправляются в облако с небольшой задержкой.
- При потенциальном конфликте система не перезаписывает более новую облачную версию молча.

СОХРАННОСТЬ
- STORAGE KEY не менялся: king_os_v1.
- Схема: 12.
- История работы, тренировок, RIR, книг, дел и Tracker сохраняется.
