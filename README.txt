KING OS V2.3

TRACKER
- «Режим · дней подряд» теперь строгий: любой отмеченный «Нет» сразу обнуляет именно streak режима.
- При этом первый «Нет» за неделю по-прежнему может быть льготным для идеального дня.
- «Идеальных дней» теперь показывает текущую серию идеальных дней подряд, а не общее число за всё время.
- Корректный выходной от работы остаётся нейтральным и не увеличивает/не обрывает соответствующие серии.
- Некорректный выходной (спорт не закрыт или есть зависимость) прерывает счётчики.

WORK OS — новая система с 21.09.2026
- У каждого дня больше нет обязательной нормы часов.
- Пользователь вручную отмечает рабочий день как «Успешный» / «Неуспешный».
- Локальная отметка является главным критерием конкретного дня.
- Недельная цель: 60 рабочих часов суммарно по всем проектам.
- Пока неделя идёт, локальные отметки работают независимо от количества часов.
- После закрытия недели, если суммарно <60 ч, все локальные «Успешный» за эту неделю автоматически перестают засчитываться.
- Если позже добавить часы за прошлые дни и довести закрытую неделю до 60 ч, локальные успешные отметки восстанавливаются автоматически.
- Прошлые рабочие правила до 21.09.2026 сохранены исторически.

ПРОЕКТЫ
- Dark EVERY убран из активных проектов с 21.09.2026, но его старая история не удаляется.
- ЭВЕРИ остаётся основным проектом.
- «Другое» остаётся дополнительным динамическим проектом.
- Можно добавить ещё два дополнительных динамических проекта (до 3 дополнительных проектов суммарно).
- Дополнительные проекты можно переименовать; созданные дополнительно — убрать из активных без удаления истории.

РАБОЧИЙ ЭКРАН
- Работа перенесена в центр нижнего меню.
- Вверху показывается прогресс текущей недели: X / 60 часов.
- Отдельный блок ручной оценки сегодняшнего рабочего дня.
- Ниже — часы и комментарии по проектам.
- Дела по датам показаны компактной лентой + календарём.
- Добавлен блок «Без даты»: туда можно складывать дела, идеи и мысли без календарной даты.
- Элементы «Без даты» можно редактировать и удалять; дела можно отмечать выполненными.

ТРЕНИРОВКИ

- RIR хранится вместе с весом и повторами.

- Старые подходы получают пустой RIR, остальные тренировочные данные сохраняются.
