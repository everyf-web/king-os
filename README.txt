KING OS V3.1.1 · RELEASE
Дата: 21.10.2026 · новый отсчёт с 22.10.2026

ЧТО ИЗМЕНИЛОСЬ
1. Новый раздел «Мысли и дела» (кнопка «Мысли» внизу). Можно создавать разделы и подразделы любой глубины, добавлять записи и задачи, редактировать/перемещать их, отмечать выполненные задачи, искать по всем папкам. Удаление непустых разделов блокируется, чтобы не потерять содержимое.
2. Порно / эротика — нарушение в любой день, включая выходной. Нарушенный день красный; счётчики и идеальный день не засчитываются.
3. Мастурбация — разрешён 1 раз за календарную неделю (ПН–ВС). Второй и последующие разы можно зафиксировать честно, но дата второго и последующих случаев становится красной, а серия дисциплины прерывается.
4. «Тренировка ПА» — отдельная независимая отметка (не более одного раза ПН–ВС), дополнительная попытка до следующей недели блокируется. Важно: если при ней была мастурбация, факт мастурбации отмечается отдельно — система не предполагает его автоматически.
5. Трекер показывает счётчик дней без нарушений, неделю по мастурбации 0/1 и тренировкам ПА 0/1. Для выходных продолжают действовать только правила дисциплины; остальные ежедневные условия необязательны. Недельная норма работы 60 ч сохраняется.
6. Новая дата отсчёта 22.10.2026. Ранние дни в календаре скрыты. Старые данные НЕ удаляются, история старых тренировок сохраняется для сравнения результатов.
7. Первая неполная неделя 22–25.10.2026 — переходная, на неё не распространяются штрафы за недобор недельных норм работы и спорта. Первые полные нормативы с понедельника 26.10.2026.
8. Спорт V3.0, курс 54 тем, сон 00:00/08:00, работа, чтение — сохранены.

БАЗА / МИГРАЦИЯ
LocalStorage: king_os_v1 (ключ не изменяется).
V3.1.0 мигрирует данные однократно без удаления исторических фактов.
Старые записи из прежних Work Inbox и календарных задач (если были) копируются в папку «Из прежней версии» в новом разделе; исходные записи остаются в базе.

УСТАНОВКА НА GITHUB PAGES
1. Сначала В СТАРОЙ KING OS с телефона с данными: ⚙ → Экспорт JSON; файл сохранить отдельно.
2. Распаковать архив; загрузить 7 файлов архива в корень репозитория everyf-web/king-os с заменой файлов.
3. Дождаться обновления GitHub Pages и открыть https://everyf-web.github.io/king-os/ . В заголовке ожидается V3.1.1.
4. Если на телефоне открывается старая версия, открыть https://everyf-web.github.io/king-os/?repair=1. Repair обновит SW/cache; localStorage не удаляется.
5. Импорт JSON требуется ТОЛЬКО если локальных данных не оказалось. Импорт перепишет базу на устройстве; НЕ импортируйте случайные файлы.

ВАЖНО
Данные хранятся в localStorage каждого браузера и не синхронизируются между устройствами.
По решению пользователя система поставляется сейчас без обязательного пользовательского тестирования перед деплоем.


ИСПРАВЛЕНИЕ V3.1.1 · РЕДАКТОР ДНЯ
- Нажатие на дату в Tracker сразу открывает полноценный редактор, а не только кнопку «Выходной».
- Доступны любые даты начиная с 22.10.2026, включая будущие (можно заполнить день заранее).
- В редакторе: рабочие часы и результаты по проектам, успешность дня, силовая/бокс, сон 08:00/00:00, чтение, питание, порно, мастурбация, тренировка ПА, выходной.
- Кнопка «Сводка дня» позволяет просмотреть статусы без редактирования, из неё есть кнопка «Редактировать».
- Выходной можно менять непосредственно в редакторе, изменения применяются вместе с остальными полями после «Сохранить».
- Ключ localStorage и данные не меняются, импорт не нужен; перед обновлением всё же рекомендуется экспорт JSON.
- Для обновления кэша используется новый номер версии Service Worker.
