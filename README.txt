KING OS V1.9

Изменения:
1. Sport OS показывает историю всех завершённых тренировок.
2. В любой активной или завершённой тренировке можно изменить дату. Дата startedAt/endedAt сдвигается вместе с тренировкой, чтобы сортировка не ломалась.
3. В модальном окне тренировки можно сохранить вес тела на дату тренировки.
4. Добавлен режим сна: лечь до 03:00, встать до 10:00, плюс приблизительное количество сна. Режим — отдельная привычка и входит в идеальный день.
5. Работа: с 05.09.2026 норма — строго более 9 часов суммарно. ЭВЕРИ — основной, Dark EVERY — дополнительный, Проект 3 переименован в «Другое». Исторические дни до 05.09.2026 сохраняют прежнюю норму >=10 часов.
6. Tracker на телефоне: день показывает X/5 и пять компактных полосок (Работа / Спорт / Чтение / Режим / Чисто). Тап по дню открывает подробный чек-лист.

STORAGE KEY не менялся: king_os_v1.
