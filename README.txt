KING OS V2.5

ИЗМЕНЕНИЕ ИДЕАЛЬНОГО ДНЯ — С 28.09.2026

1. Чтение становится опциональным для идеального дня.
   - Отсутствие чтения больше не мешает получить идеальный день.
   - Сам Reading OS не меняется.
   - Tracker продолжает считать реальную текущую серию дней чтения подряд.
   - Серия чтения считается по календарным дням и не зависит от выходных/идеального дня.

2. Мастурбация становится опциональной для идеального дня.
   - Отметка мастурбации больше не лишает день статуса «идеальный».
   - Tracker отдельно показывает текущую серию дней без мастурбации.
   - История отметок сохраняется.

3. Порно / эротика остаётся обязательным условием.
   - Любая отметка порно по-прежнему делает день неидеальным.
   - Tracker отдельно показывает серию дней без порно.

4. История до 28.09.2026 не переписывается.
   - До этой даты чтение обязательно для идеального дня.
   - До этой даты отсутствие мастурбации обязательно для идеального дня.

TRACKER
- Вместо общего «Без зависимостей» теперь два независимых счётчика:
  • Без порно · дней подряд
  • Без мастурбации · дней подряд
- Чтение · дней подряд остаётся отдельным счётчиком.
- В календаре с 28.09 идеальный день считается по 4 обязательным условиям:
  Работа + Спорт + Режим + Без порно.
- До 28.09 сохраняется историческая схема из 5 условий.
