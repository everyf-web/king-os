WORK OS — с 09.09.2026
Рабочий день засчитывается при выполнении всех целей ЭВЕРИ:
1. Дешёвый продукт — 5 ч
2. Входящий поток — 1 ч
3. Партнёрский поток — 1 ч
4. Организация бизнеса — 1 ч

Dark EVERY и «Другое» можно вести, но они не обязательны для зачёта дня.
Для времени по-прежнему нужен результат работы минимум из двух слов.
Поля результатов значительно увеличены.

Исторические правила сохраняются:
- до 05.09.2026: >=10 ч
- 05.09–08.09.2026: >9 ч
- с 09.09.2026: четыре цели ЭВЕРИ.

НЕЙТРАЛЬНЫЙ ВЫХОДНОЙ
- В Tracker можно открыть день и нажать «Взять целый выходной».
- Такой день отмечается зелёным как ВЫХ.
- Он не увеличивает и не обрывает streaks.
- Он не добавляется в число идеальных дней.
- Он исключается из недельных знаменателей ideal/habit completion.
- При этом в нём можно записывать тренировку, чтение, сон и другие факты.
- Выходной можно снять обратно.
